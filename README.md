## Windhawk Mods
Here are all the mods I've created for Windhawk.

Name | Version | Description | Link |
|---|---|---|---|
| `Taskbar Fluent Media Player` | 1.6.0 | Adds a Fluent Design media player flyout to the Windows taskbar. | [GitHub](https://github.com/Salyts/Taskbar-Fluent-Media-Player), [Windhawk](https://windhawk.net/mods/taskbar-fluent-media-player), [Discord discussion](https://discord.com/channels/923944342991818753/1508829079187619840). |
| `Windows 11 Start Menu Buttons` | 2.2 | Customizable buttons for the Windows 11 Start menu. | [GitHub](https://github.com/Salyts/Windows-11-Start-Menu-Buttons), [Windhawk](https://windhawk.net/mods/windows-11-start-menu-buttons). |
| `Windows 11 Control Center Buttons` | 1.0.0 | Replaces the gear button in the Windows 11 Control Center footer with fully customizable buttons | [GitHub](https://github.com/Salyts/Windows-11-Control-Center-Buttons), [Windhawk](https://windhawk.net/mods/windows-11-control-center-buttons), [Discord discussion](https://discord.com/channels/923944342991818753/1558419938820227123). |
| `Ultimate Custom Tray` | 2.1 | Adds customizable tray icons with actions, menus, app/image icons, and theme support. | [GitHub](https://github.com/Salyts/Ultimate-Custom-Tray), [Windhawk](https://windhawk.net/mods/ultimate-custom-tray). |
| `Desktop Audio Visualizer` | 1.0.0 | Real-time audio visualizer on your Windows desktop with customizable appearance. | [Windhawk](https://windhawk.net/mods/desktop-audio-visualizer). |
| `Mod Manager Tray` | 1.3 | Adds a tray icon to toggle Windhawk mods. | [GitHub](https://github.com/Salyts/Mod-Manager-Tray), [Discord discussion](https://discord.com/channels/923944342991818753/1556683753923809321). |
| `Window Center & Resize` | 1.0 | Centers and resizes the foreground window using global hotkeys. | [Windhawk](https://windhawk.net/mods/window-center-resize). |
